# Trade101 — MVP Design Spec

**Date:** 2026-09-09
**Status:** Draft for review
**Author:** Pranav (with Claude)

---

## 1. Overview

**Trade101** is a personal stock-research **and learning** desktop-web app. Its job is to help the user (a student, beginning trader) learn market metrics *hands-on, in context, on real stocks* — while assembling source-backed research (prices, indicators, news, filings, ecosystem) in one place.

**Core guardrail:** the AI **describes momentum and explains metrics with sourced evidence; it never predicts profit or says buy/sell.** It is a data-analytics + learning tool, not a signal generator.

### Principles
- **Numbers are exact, opinions are sourced.** Mechanical work (prices, indicators) is deterministic code that cannot hallucinate; judgment (news relevance, momentum read, inferences) is done by agents that must cite every claim.
- **Learn in context.** Every metric is explained *on the stock currently open*, not in the abstract.
- **Airy, interactive, appealing** UI — richer than Zerodha, calmer than Moomoo.
- **Flexible, content-sized layout** — no rigid boxes; blocks grow to their content.

## 2. Architecture (hybrid: deterministic services + agents)

```
Frontend (React + Vite)
   │  JSON over REST
Backend (FastAPI, Python)
   ├── Orchestrator  ──────────────┐
   ├── Deterministic services      │ coordinates
   │     • MarketData (yfinance)   │
   │     • Indicators (pandas)     │
   │     • Patterns (scipy extrema)│
   │     • NewsFetch (providers)   │
   │     • Storage (SQLite)        │
   └── Agents (Claude API)         │
         • Research  ◀─────────────┘
         • Analysis
         • Ecosystem
```

### 2.1 Frontend — React + Vite
- **Welcome page** (Gemini/Claude style): slim left rail (New research · Comparison · History · recent tickers), centered prompt "Which stock shall we study?", search box + suggestion chips.
- **Research view** (per locked v5 mockup): Trade101 top bar + tabs (Research/Comparison/History); headline (ticker, price, momentum chip); **cockpit** [live chart + `Patterns` button → slide-out panel with magnifier | AI momentum read]; **mid** [merged Metrics & Learning (click metric → contextual lesson, Esc to close) | News block with **Feed** + **What it means** tabs]; full-width **Ecosystem + index** (S&P/NASDAQ, beta); **References** box; **Ask Claude** button (Phase 2).
- **Chart:** TradingView **Lightweight-Charts** (free library) rendering Yahoo data, delayed & auto-refreshed on an interval; clearly labeled "delayed ~15m". (Option: embed the free TradingView widget for the exact TV look.)
- **Palette:** dark fintech, derived from the Trade101 logo — ground `#0E1A26`, surface `#152534`, teal `#34A9BE` (interactive), green `#00D68F` (up), red `#F0616D` (down). Colors are MVP-tunable later.

### 2.2 Deterministic services (no LLM — exact)
| Service | Does | Tech |
|---|---|---|
| **MarketData** | quote, OHLCV history, financial statements | `yfinance` (reuses the existing Yahoo Finance MCP work); **pluggable** — Stooq / Alpha Vantage / Finnhub can be added later |
| **Indicators** | RSI(14), MACD(12,26,9), SMA/EMA 50/200, Bollinger(20,2), volume | `pandas` / `pandas-ta`; unit-tested against known values |
| **Patterns** | detect triple-top/bottom & head-and-shoulders; return swing points to draw + confidence | `scipy.signal` extrema |
| **NewsFetch** | fetch company news/filings | provider interface (default a free news API; SEC EDGAR for filings) |
| **Storage** | save research history (ticker, timestamp, 2-line summary), cache | SQLite |

### 2.3 Agents (Claude API — judgment only)
- **Orchestrator** — coordinates a research run; mostly deterministic, may make a light planning call.
- **Research agent** — decides *what* to search, calls the **scrape/search tools** (news API + a scrape provider: **Firecrawl / Bright Data / Exa**), filters for relevance, returns structured **sourced** items. The agent judges; the tools fetch (efficient — the LLM never parses raw HTML).
- **Analysis agent** — given the *exact* indicators + sourced news, writes: the **momentum read** (bull/bear + confidence + sourced "why"), the **contextual metric lessons**, and the news **"What it means"** inference. Receives numbers as inputs; never computes them.
- **Ecosystem agent** — maps supply-chain / linked companies, index membership, and beta.

## 3. Data flow — one search

`POST /research/{ticker}` → Orchestrator:
1. `MarketData.get(ticker)` → price, OHLCV, financials
2. `Indicators.compute(OHLCV)` → RSI, MACD, SMAs, BB, volume
3. `Patterns.detect(OHLCV)` → patterns + points (for the magnifier)
4. `NewsFetch` + **Research agent** → sourced news/filings
5. **Analysis agent**(numbers + news) → momentum read, metric lessons, "what it means"
6. **Ecosystem agent**(company) → chain + index + beta
7. `Storage.save(ticker, 2-line summary)`
→ returns one **research bundle** (JSON) → frontend renders the Research view.

---

## 4. Anti-hallucination contract
- Agents **receive exact numbers as input**; a guard **rejects any numeric claim lacking a citation**.
- **Every AI statement carries a source** (filing / Yahoo / news URL) → aggregated in the References box.
- AI outputs a **momentum read with confidence + evidence**, and **never** buy/sell/price-target advice.
- Unreachable/paywalled source → **stated as such**, never fabricated. Delayed data always labeled.

## 5. Config & API keys
- **Separate, named Claude API keys per component** (per-component usage tracking + isolation): `Trade101-Orchestrator`, `Trade101-Research`, `Trade101-Analysis`, `Trade101-Ecosystem`.

## 6. MVP scope

**In:**
- Welcome page → Research view for **US tickers** (NVDA as the working example)
- Delayed auto-refreshing chart (Lightweight-Charts)
- Indicators (RSI, MACD, SMA 50/200, Bollinger, Volume) with **click-to-learn** contextual lessons (standard trader symbols)
- AI **momentum read** (sourced, confidence, no buy/sell)
- **News: Feed + "What it means"** inference (sourced)
- **Ecosystem chain + index/beta** learning
- **References** box (all sources)
- Basic saved **history**
- **Patterns** button + magnifier with triple-top/bottom + head-and-shoulders detection

**Out (later phases):**
- The other 6 markets (China/Japan/Korea/HK/Singapore/India) — pluggable data sources
- Comparison tab · full History UI
- **Ask Claude** chat (architecture is chat-ready; wired in Phase 2)
- Richer pattern library + step-by-step teaching replay
- Real logo (from the user's data-cube spec) · desktop packaging (Tauri/Electron) · auth

## 7. Resilience / error handling
- **Unknown ticker** → clear message + suggestions.
- **Data source down / rate-limited** → show what's available, mark what's missing ("news unavailable"), never invent.
- **AI layer fails/times out** → the chart + indicators **still render**; the deterministic view never depends on the agent. Retry with backoff.
- **Multi-market** (later): each market a data-source adapter; unsupported → say so.

---

## 8. Testing
- **Exact-number unit tests** for every indicator (RSI/MACD/SMA vs known fixtures) — critical.
- **Pattern tests** on synthetic price series.
- **Citation-guard test** — reject agent output with unsourced numeric claims.
- **Smoke test** — `GET /research/NVDA` returns a complete, well-formed bundle.
- **Frontend** — render tests for each Research-view zone.
